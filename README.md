# ระบบบันทึกการพัฒนาตนเอง v2.0 (Enhanced Personal Development Tracking System)

เว็บแอปพลิเคชันสำหรับติดตามและบันทึกการพัฒนาตนเองอย่างครบถ้วน พร้อมฟีเจอร์ขั้นสูงและระบบแจ้งเตือน

## 🚀 ฟีเจอร์ใหม่ในเวอร์ชัน 2.0

### 🔔 ระบบแจ้งเตือน (Notification System)
- แจ้งเตือนเมื่อทำนิสัยเสร็จสิ้น
- แจ้งเตือนเมื่อบรรลุเป้าหมาย
- แจ้งเตือนตามเวลาที่กำหนด
- ระบบเกียรติบัตรและความสำเร็จ

### ⚙️ ระบบตั้งค่า (Settings)
- เปิด/ปิดการแจ้งเตือน
- ตั้งเวลาแจ้งเตือนนิสัยและเป้าหมาย
- เปลี่ยนธีม (สว่าง/มืด/อัตโนมัติ)
- ปรับสีหลักของแอป

### 📊 ระบบรายงานขั้นสูง (Advanced Analytics)
- สรุปรายสัปดาห์
- แสดงความสำเร็จล่าสุด
- กราฟสถิติแบบละเอียด
- ระบบเกียรติบัตร

### 💾 การจัดการข้อมูล (Data Management)
- ส่งออกข้อมูลเป็นไฟล์ JSON
- นำเข้าข้อมูลจากไฟล์
- สำรองข้อมูลอัตโนมัติ
- กู้คืนข้อมูล

## ✨ ฟีเจอร์หลัก

### 🎯 การจัดการเป้าหมาย (Goals Management)
- สร้างและติดตามเป้าหมายในหมวดหมู่ต่างๆ
- ตั้งระดับความสำคัญ (สูง/ปานกลาง/ต่ำ)
- ติดตามความก้าวหน้าด้วยเปอร์เซ็นต์
- กำหนดวันที่เป้าหมาย
- แก้ไขและลบเป้าหมายได้

### 📅 การติดตามนิสัย (Habit Tracking)
- สร้างนิสัยใหม่และติดตามความถี่
- ปฏิทินแสดงสถานะการทำนิสัย
- นับจำนวนวันที่ติดต่อกัน (Streak)
- ตั้งเป้าหมายจำนวนครั้งต่อสัปดาห์
- หมวดหมู่นิสัยที่หลากหลาย

### 🎓 การพัฒนาทักษะ (Skills Development)
- เพิ่มทักษะที่ต้องการพัฒนา
- ตั้งระดับปัจจุบันและเป้าหมาย (1-10)
- ติดตามความก้าวหน้าในการพัฒนาทักษะ
- หมวดหมู่ทักษะที่ครอบคลุม

### 📊 แดชบอร์ดและวิเคราะห์ (Dashboard & Analytics)
- สถิติสรุปภาพรวม
- กราฟแสดงความก้าวหน้าเป้าหมาย
- กราฟสถิตินิสัย 7 วันล่าสุด
- กราฟเรดาร์แสดงการพัฒนาทักษะ
- งานที่ต้องทำวันนี้

## 🚀 วิธีการใช้งาน

### การติดตั้ง
1. ดาวน์โหลดไฟล์ทั้งหมด
2. เปิดไฟล์ `index.html` ในเบราว์เซอร์
3. หรือรันเซิร์ฟเวอร์ท้องถิ่น:
   ```bash
   python3 -m http.server 8000
   ```
   แล้วเปิด `http://localhost:8000`

### การใช้งานเบื้องต้น
1. **เริ่มต้นด้วยการตั้งเป้าหมาย**: คลิก "เพิ่มเป้าหมายใหม่" และกรอกข้อมูล
2. **สร้างนิสัย**: เพิ่มนิสัยที่ต้องการทำเป็นประจำ
3. **พัฒนาทักษะ**: เพิ่มทักษะที่ต้องการพัฒนา
4. **ติดตามความก้าวหน้า**: ดูสถิติและกราฟในแท็บ "ความก้าวหน้า"

## 🎨 ฟีเจอร์ UI/UX

- **ดีไซน์โมเดิร์น**: ใช้สีไล่โทนและเอฟเฟกต์ Glassmorphism
- **Responsive Design**: ใช้งานได้บนทุกอุปกรณ์
- **Thai Language Support**: ภาษาไทยครบถ้วน
- **Interactive Charts**: กราฟแบบอินเทอร์แอคทีฟด้วย Chart.js
- **Smooth Animations**: เอฟเฟกต์การเคลื่อนไหวที่นุ่มนวล

## 💾 การจัดเก็บข้อมูล

- ใช้ **localStorage** ในการจัดเก็บข้อมูล
- ข้อมูลจะถูกบันทึกอัตโนมัติ
- ไม่ต้องติดตั้งฐานข้อมูล
- ข้อมูลจะอยู่เฉพาะในเครื่องของคุณ

## 📱 การรองรับอุปกรณ์

- ✅ Desktop (Windows, macOS, Linux)

## 🛠️ เทคโนโลยีที่ใช้

- **HTML5**: โครงสร้างหน้าเว็บ
- **CSS3**: การออกแบบและ Responsive Design
- **JavaScript (ES6+)**: ฟังก์ชันการทำงาน
- **Chart.js**: กราฟและแผนภูมิ
- **Font Awesome**: ไอคอน
- **LocalStorage API**: การจัดเก็บข้อมูล
