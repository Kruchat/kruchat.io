# คู่มือการใช้งานและติดตั้งระบบ KruChat.io

## ภาพรวม
KruChat.io เป็นเดสก์ท็อปแอปพลิเคชันที่สร้างด้วย [Tauri](https://tauri.app) และส่วนติดต่อผู้ใช้จากเว็บเทคโนโลยี เพื่อช่วยจัดการข้อมูลนักเรียน เอกสารหลักฐาน และการค้นหาไฟล์ร่วมกับ Google Drive ภายในองค์กรการศึกษา การทำงานหลักๆ ประกอบด้วยโมดูลคลังเอกสาร โมดูลข้อมูลนักเรียน และเครื่องมือช่วยสร้างรายงานอย่างรวดเร็ว

## ความต้องการเบื้องต้น
ก่อนเริ่มติดตั้ง กรุณาติดตั้งซอฟต์แวร์ต่อไปนี้ให้พร้อม

- [pnpm](https://pnpm.io/installation) เวอร์ชัน 8 ขึ้นไป เพื่อจัดการแพ็กเกจ JavaScript
- [Rust toolchain](https://www.rust-lang.org/tools/install) ผ่าน `rustup` (รวมทั้ง `cargo` และชุดเครื่องมือ C++ ที่ Tauri ต้องการ)
- Git สำหรับโคลนซอร์สโค้ด (หรือดาวน์โหลด ZIP ก็ได้)

> เคล็ดลับ: ถ้าติดตั้ง Rust เป็นครั้งแรก ให้สั่ง `rustup target add wasm32-unknown-unknown` หลังจากติดตั้งเสร็จ เพื่อรองรับไลบรารีบางส่วนของ Tauri

## ขั้นตอนติดตั้งตามระบบปฏิบัติการ

### Windows
1. ติดตั้ง [Node.js LTS](https://nodejs.org/en) (เพื่อให้มี npm ไว้ติดตั้ง pnpm) แล้วรัน `npm install -g pnpm`
2. ติดตั้ง Visual Studio Build Tools (เลือก Desktop development with C++) เพื่อให้ได้ MSVC, Windows SDK ที่จำเป็นต่อ Tauri
3. ติดตั้ง Rust ด้วย `rustup-init.exe` แล้วเปิด PowerShell ใหม่เพื่อให้ PATH ทำงาน
4. โคลนโปรเจ็กต์ `git clone https://github.com/…/kruchat.io.git` แล้ว `cd kruchat.io`
5. รัน `pnpm install` เพื่อติดตั้ง dependencies

### macOS
1. ติดตั้ง [Homebrew](https://brew.sh/) แล้วรัน `brew install pnpm rustup` (หรือใช้ `curl` เพื่อติดตั้งแต่ละตัวแยกกัน)
2. รัน `rustup-init` และทำตามขั้นตอน จากนั้นติดตั้ง Xcode Command Line Tools ด้วย `xcode-select --install`
3. โคลนโปรเจ็กต์ `git clone … && cd kruchat.io`
4. รัน `pnpm install`

### Linux (Debian/Ubuntu)
1. ติดตั้งไลบรารีระบบ: `sudo apt update && sudo apt install -y build-essential libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev curl`
2. ติดตั้ง pnpm ด้วย `curl -fsSL https://get.pnpm.io/install.sh | sh -`
3. ติดตั้ง Rust ผ่าน `curl https://sh.rustup.rs -sSf | sh`
4. โคลนโปรเจ็กต์และติดตั้ง dependencies ด้วย `pnpm install`

> สำหรับดิสทริบิวชันอื่น ตรวจสอบรายการไลบรารีที่ Tauri ต้องใช้จากเอกสารทางการ และปรับคำสั่งให้เหมาะสม

## การรันและการคอมไพล์
- โหมดพัฒนา (มี hot reload): `pnpm tauri dev`
- สร้างไฟล์ปฏิบัติการพร้อมแจกจ่าย: `pnpm tauri build`

ไฟล์ build จะถูกสร้างภายใต้ `src-tauri/target` ตามแพลตฟอร์มที่ใช้งาน

## การจัดเก็บฐานข้อมูลและหลักฐาน
- ระหว่างพัฒนา: ฐานข้อมูล SQLite จะถูกสร้างไว้ที่ `src-tauri/prisma/dev.db`
- หลัง build: Tauri จะย้ายฐานข้อมูลไปไว้ในไดเรกทอรีข้อมูลผู้ใช้ของระบบ (เช่น `%AppData%\com.kruchat.app`, `~/Library/Application Support/com.kruchat.app`, `~/.local/share/com.kruchat.app`)
- ไฟล์หลักฐาน (เช่น รูปภาพหรือสแกนเอกสาร) จะถูกบันทึกในโฟลเดอร์ `storage/evidence` ภายในไดเรกทอรีเดียวกับฐานข้อมูล หากเชื่อมต่อ Google Drive ระบบจะดึงลิงก์ไฟล์ภายนอกมาจัดเก็บในฐานข้อมูลเท่านั้น

> อย่าลืมสำรองทั้งไฟล์ `.db` และโฟลเดอร์ `storage/evidence` ทุกครั้งก่อนอัปเดตหรือย้ายเครื่อง

## บทบาทผู้ใช้และข้อมูลเข้าสู่ระบบเริ่มต้น
| บทบาท | สิทธิ์ | วิธีเข้าสู่ระบบ |
|-------|--------|------------------|
| ผู้ดูแลระบบ (Admin) | จัดการข้อมูลทั้งหมด, ดูรายงาน, ส่งออกข้อมูล | ชื่อผู้ใช้ `admin` / รหัสผ่าน `1234` (ค่าเริ่มต้น สามารถแก้ไขในฐานข้อมูล) |
| ครู/เจ้าหน้าที่ | อ่านข้อมูลและบันทึกหลักฐาน (จำกัดการตั้งค่า) | ให้ผู้ดูแลเพิ่มบัญชีใหม่ผ่านหน้าจัดการผู้ใช้ |
| ผู้ชม (อ่านอย่างเดียว) | เปิดอ่านข้อมูล, สร้างรายงานอ่านอย่างเดียว | ใช้บัญชีที่ผู้ดูแลสร้างแบบอ่านอย่างเดียว |

> หลังติดตั้งครั้งแรกระบบมีเฉพาะบัญชีผู้ดูแล (`admin` / `1234`) สำหรับทดลองใช้งาน ควรเปลี่ยนรหัสผ่านทันทีและเพิ่มบัญชีอื่นตามนโยบายความปลอดภัยของสถานศึกษา

## การสำรองข้อมูลและกู้คืน
1. **สำรองฐานข้อมูล**: ปิดแอป จากนั้นคัดลอกไฟล์ `dev.db` (หรือไฟล์ `.db` ในไดเรกทอรีข้อมูลผู้ใช้) ไปเก็บไว้ในที่ปลอดภัย พร้อมทั้งโฟลเดอร์ `storage/evidence`
2. **สำรองผ่านคำสั่ง** (เลือกอย่างใดอย่างหนึ่ง):
   - `pnpm prisma db pull --schema src-tauri/prisma/schema.prisma` เพื่อดึงโครงสร้างล่าสุดก่อนสำรอง
   - `pnpm prisma migrate diff --from-empty --to-schema-datamodel src-tauri/prisma/schema.prisma --script > backup.sql` เพื่อสร้างสคริปต์ SQL สำรองโครงสร้างและข้อมูลพื้นฐาน
3. **กู้คืน**: นำไฟล์ `.db` และโฟลเดอร์ `storage/evidence` ที่สำรองไว้ไปวางทับตำแหน่งเดิม จากนั้นเปิดแอปอีกครั้ง หากฐานข้อมูลมีการอัปเกรดสคีมา ให้รัน `pnpm prisma migrate deploy` เพื่ออัปเดตโครงสร้าง

## การส่งออกข้อมูล
- เมนูส่งออกในแอปจะสร้างไฟล์ CSV/Excel ตามที่เลือก แล้วบันทึกไว้ในโฟลเดอร์ `exports` (หรือกดดาวน์โหลดจากเบราว์เซอร์ภายในแอป)
- สำหรับการส่งออกผ่าน CLI สามารถใช้ `pnpm prisma db export --url "file:./src-tauri/prisma/dev.db" --output exports/export.sql`
- หากต้องการข้อมูลแบบ JSON ให้ใช้สคริปต์ผู้ดูแล (`pnpm run export:json`) ซึ่งอ่านข้อมูลจากฐาน SQLite แล้วสร้างไฟล์ที่ `exports/data.json`

## การทำงานออฟไลน์
- โมดูลค้นหาเอกสารพึ่งพา Google Apps Script/Google Drive จึงต้องมีการเชื่อมต่ออินเทอร์เน็ต หากทำงานออฟไลน์จะเห็นข้อความแจ้งข้อผิดพลาดและไม่สามารถค้นหาไฟล์ใหม่ได้
- โมดูลฐานข้อมูลนักเรียนและรายงานสามารถใช้งานออฟไลน์ได้เต็มรูปแบบ เพราะข้อมูลอยู่ใน SQLite ภายในเครื่อง เมื่อกลับมาออนไลน์ ระบบจะซิงก์ไฟล์หลักฐานไปยัง Google Drive ตามคิวที่รออยู่
- แนะนำให้เปิดแอปอย่างน้อยสัปดาห์ละครั้งในโหมดออนไลน์เพื่อให้การซิงก์เสร็จสมบูรณ์

## การ Seed หรือรีเซ็ตฐานข้อมูล
- เติมข้อมูลตัวอย่าง: `pnpm prisma db seed`
- รีเซ็ตฐานข้อมูลกลับค่าเริ่มต้น (ลบข้อมูลเดิมทั้งหมด): `pnpm prisma migrate reset`
- หากต้องการ seed เฉพาะชุดข้อมูลนักเรียน ให้ใช้ `pnpm run seed:students`
- สำหรับการรีเฟรชเฉพาะข้อมูลเอกสาร: `pnpm run seed:documents`

> ทุกคำสั่งข้างต้นจะลบข้อมูลเดิม ควรสำรองก่อนดำเนินการ

## แนวทางแก้ปัญหาเบื้องต้น
- **คอมไพล์ไม่ผ่าน**: ตรวจสอบว่า Rust ติดตั้งครบและอัปเดตด้วย `rustup update` รวมถึงใช้ pnpm เวอร์ชันล่าสุด
- **เปิดแอปแล้วจอดำ**: ลบโฟลเดอร์ cache ของ Tauri ในไดเรกทอรีข้อมูลผู้ใช้ แล้วลองรัน `pnpm tauri dev` อีกครั้ง
- **เชื่อมต่อ Google Drive ไม่ได้**: ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต และว่าลิงก์ Google Apps Script ในไฟล์ `documents.html` ยังถูกต้องอยู่
- **ฐานข้อมูลเสียหาย**: ปิดแอปแล้วคืนค่าจากไฟล์สำรอง หรือรัน `pnpm prisma migrate reset` แล้ว `pnpm prisma db seed`
- **การล็อกอินล้มเหลว**: ตรวจสอบว่าชื่อผู้ใช้/รหัสผ่านถูกต้อง (ค่าเริ่มต้น `admin` / `1234`) และล้าง Local Storage หากทดสอบบนเบราว์เซอร์ฝังของ Tauri
